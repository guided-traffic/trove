## 0 · What T-18 changes, in one paragraph

One mechanism opens content: a level `private`, `internal` or `public` on each project and on each repository's artifacts and
wiki, bounded by the project, copied from the installation's default at create, lowered with the project. `public` reads for every
request, `internal` for every user through a session or a personal token who is not flagged `external` and not through a Bastion.
The runtime switch `anonymousAccess`, its YAML ceiling `auth.anonymous.allowed`, the repository member `requireAuthentication`,
the principal `authenticated` and every policy entry for `anonymous` are removed, not deprecated (pre-alpha: no backward compatibility until the first stable release). The wiki
is decided by one coordinate part; a caller without it gets wiki routes refused and wiki members absent.

// Level is a visibility level (R-AUTHZ-033), ordered from the most restrictive.
type Level uint8

const (
	LevelPrivate Level = iota
	LevelInternal
	LevelPublic
)

func ParseLevel(s string) (Level, bool) // "private", "internal", "public"
func (l Level) String() string

// Part is the part of a repository a coordinate reads (R-AUTHZ-034). The zero value is the artifacts, so every existing
// coordinate keeps its meaning.
type Part uint8

const (
	PartArtifacts Part = iota
	PartWiki
)

type Coordinate struct {
	// ...existing fields...
	Part Part // a coordinate with PartWiki asks only Read; any other action is a programming error and is refused
}

type Subject struct {
	// ...existing fields, without the unexported anon state...
	// External is the user's external flag as the authentication stage resolved it with status and groups (R-AUTH-044).
	External bool
	// ViaBastion says the request reached the main installation through a recognized Bastion forward or the Bastion
	// check (R-BAS-008, Q-BAS-148). Both are set by edge.SubjectOf only; the architecture test refuses any other writer,
	// as for Endpoint.
	ViaBastion bool
}

// Internal reports R-AUTHZ-030: a user (KindUser or break-glass) with a session or a personal token, not External, not
// ViaBastion. Service accounts, CI, Bastion and anonymous subjects are never internal.
func (s Subject) Internal() bool

// Options: the field AnonymousAccess is deleted.

// Reasons (errors.go): ReasonAllowVisibility = "allow.visibility", ReasonWiki = "deny.wiki".

// AuthenticatedID and dbAuthenticated are deleted; AnonymousID stays (the actor of a request without a credential).
