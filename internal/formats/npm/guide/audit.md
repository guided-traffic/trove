trove sends only the names the forwarding remote repository has fetched from its upstream already, and of those none that is internal: no name that exists in a local repository, falls under a namespace claim or a pin rule, or that the repository's patterns refuse. A name trove has never fetched, such as an internal name nobody claimed or a git dependency, is withheld as well, so the provider learns no name it has not seen from this installation before. A withheld name has no advisories in the answer. npm prints how many names were withheld (`trove audited <n> of <m> packages; <k> internal or not yet proxied names were not sent to the advisory provider`); pnpm and Yarn Berry do not show that notice, so their report can be partial without saying so.

When the repository's audit is switched off, or the remote repository may not contact its upstream, the audit answers `501` `npm_audit_unavailable`; when the provider fails or does not answer in time, `502`.
